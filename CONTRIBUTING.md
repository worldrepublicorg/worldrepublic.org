# Contributing to the World Republic

We're building the infrastructure for global representative democracy, and we welcome your help. To keep the project high-quality and maintainable, please follow these guidelines.

## Getting started

1. **Fork and clone**: Fork the repository and clone it to your local machine.
2. **Install dependencies**: Use `pnpm install`.
3. **Environment**: Copy `.env.example` to `.env.local` and fill in the required variables.
4. **Development**: Run `pnpm dev` to start the development server with Turbopack.

## Standards

- **Code quality**: We use [Biome](https://biomejs.dev/) for linting and formatting. Run `pnpm lint` before committing.
- **Commits**: Use clear, descriptive commit messages.
- **PRs**: Keep PRs focused. One feature or fix per PR is preferred.

## How to help

- **Report bugs**: Open an issue with steps to reproduce the bug.
- **Suggest features**: Open an issue to discuss new ideas before implementing them.
- **Submit PRs**: Ensure your code follows the existing style and passes all lint checks.

Thank you for contributing to the World Republic!
